# Character pack guidance

Use references that collectively show face shape, hair, skin details, body proportions, wardrobe, footwear, and important accessories. Avoid mixing ages, haircuts, outfits, or lighting treatments unless the brief explicitly identifies which details are canonical.

The fixed views are front full body, left three-quarter, left profile, rear full body, neutral portrait, and warm-expression portrait. Each is generated separately so the model cannot distort individual panels while composing a sheet.

If the OpenRouter plan invents an unseen detail, stop before rendering and create a new plan with a clearer brief. If a view fails review, retain it as evidence; a repair workflow must use a new explicit attempt rather than overwrite it.
