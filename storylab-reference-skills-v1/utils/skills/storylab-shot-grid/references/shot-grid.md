# Shot-grid taxonomy

The nine fixed framings are establishing, wide, full, medium, medium close-up, close-up, over-the-shoulder, high angle, and low angle. The local config records camera intent and lens language for each.

All shots use the original source frame as the only visual reference. This avoids cumulative identity and layout drift. If an over-the-shoulder composition is impossible because the source contains only one subject, keep the principal subject and scene geography intact rather than inventing an extra person.

The grid is useful for coverage exploration. A later connected-sequence workflow can add ordered action beats, but should reuse these same frozen references and never ask a model to decide continuity implicitly.
